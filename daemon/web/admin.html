Device

Read-only. This device is configured from a seed file or from Home Assistant, not from here.

Recovery

Boot an earlier system generation — use this if an update broke something. The device switches to the chosen generation and reboots. It keeps booting that one until you deploy again.

Factory reset

Clears the Home Assistant URL, the login token, the device API token and your display preferences, then reboots onto the onboarding screen. The device re-appears in Home Assistant as the same device, ready to be added again — remove the existing entry there first, because its token stops working.

This cannot be undone. Type RESET to enable the button.
