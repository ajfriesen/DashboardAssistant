# Touchscreens

A touchscreen is recommended for wall-panel use so you can wake the display and
use the on-screen controls, though it isn't required.

## Tested displays

The official Raspberry Pi touch displays are tested and working:

- **[Raspberry Pi Touch Display (7 inch)](https://www.raspberrypi.com/documentation/accessories/display.html#raspberry-pi-touch-display)** — tested and working.
- **[Raspberry Pi Touch Display 2 (10 inch)](https://www.raspberrypi.com/documentation/accessories/touch-display-2.html#raspberry-pi-touch-display-2)** — tested and working.
