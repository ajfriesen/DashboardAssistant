# Dashboard Assistant 1.3: more of the device under Home Assistant's control

Dashboard Assistant 1.3.0 and 1.3.1 give Home Assistant a lot more to control
on a device. Set its time zone and language, pick its speaker and microphone,
dim the screen saver, hide the button bar and limit how far the battery
charges, all from Home Assistant. Images now flash straight from balenaEtcher,
and updates finish with a restart. Integration 1.2.0 to 1.2.2 adds the
entities to go with it.

<!-- more -->

!!! warning "Before you update"
    - **Add your devices to your speaker groups again.** The Sendspin player is
      new, and Music Assistant sees each device as a new player after the
      update. See [A new Sendspin player](#a-new-sendspin-player).
    - **Restart the device once after updating from 1.3.0 or earlier.** Press
      **Reboot** in Home Assistant when the update is installed. Until then,
      the **Button bar** switch fails with a message asking you to restart.
      From 1.3.1 on, the device restarts by itself to finish an update.
    - **Update the integration to 1.2.2.** The new entities need it.

## Time zone and language { #time-zone-and-language }

Devices used to run on UTC with an English browser. **Configure** on a device
now opens a menu with **Pages** and **Time zone and language**. It shows
Home Assistant's own time zone and language next to the device's, so you can
match them.

- **Time zone** sets the clock on the screen saver and in every page. It takes
  effect right away.
- **Language** sets the browser's language and the on-screen keyboard's
  layout. Home Assistant pages follow it, unless the device's user picked a
  language in their profile. Changing it restarts the dashboard on the device.

## Audio output and microphone { #audio-output-and-microphone }

Devices with more than one output, such as HDMI plus a USB speaker, could play
to the wrong one, and fixing that meant a custom build. Now the **Audio
output** select in Home Assistant lists every output the device has. A USB
speaker shows up there once it is plugged in. The choice moves all of the
device's sound: Sendspin music and sound from the dashboard itself, like TTS or
a media card.

The **Audio input** select next to it picks the microphone. Nothing on the
device records from it yet; it is there for a voice assistant to use.

### A new Sendspin player { #a-new-sendspin-player }

To make this work, the device's Sendspin player is now `sendspin-cli`. It
announces itself over mDNS, and Music Assistant finds it and connects. Music
Assistant sees it as a new player, so **add each device to your speaker groups
again** after the update. [Multi-room audio](../../about/use-cases.md#audio)
has the details.

## Dim the screen saver { #dim-the-screen-saver }

**Screen saver brightness** sets how bright the panel is while the screen saver
shows. The device turns the panel down when the screen saver starts and back up
when it ends. At 0, the default, nothing changes.
[Dimming the screen saver](../../about/use-cases.md#dimming-the-screen-saver)
has an automation that uses different levels by day and by night.

## Hide the button bar { #hide-the-button-bar }

Turn off the **Button bar** switch and the dashboard gets the whole screen. The
bar's buttons go with it, so the on-screen keyboard can't be opened while the
bar is hidden.

## Reload the page { #reload-the-page }

The **Reload page** button loads the current page again, for example after you
edit a dashboard. It also happens by itself when the device's Home Assistant
user is made an administrator or stops being one, so the admin parts of Home
Assistant show or go without you doing anything.

## Battery charge limits { #battery-charge-limits }

A device that is always plugged in shouldn't sit at 100 %. On devices whose
battery supports it, **Charge start** and **Charge stop** set the percentage
below which charging starts and at which it stops. That covers, for example,
ThinkPad, Dell and ASUS laptops and tablets, which have no BIOS setting for it.
Some only have a stop. The numbers show what the battery actually accepted, and
follow a change made in the BIOS.

## Add a device on another VLAN { #add-a-device-on-another-vlan }

Discovery was the only way to add a device, and mDNS doesn't cross between
network segments. Now you can add a device by its IP address under **Add
integration → Dashboard Assistant**. It pairs the same way a discovered one
does. [Devices on another VLAN](../../getting-started.md#vlans) lists the ports
your firewall has to let through.

## Images that flash directly { #images-that-flash-directly }

Images are now `.raw.xz` files. balenaEtcher and Raspberry Pi Imager unpack
them while they flash, so there's no more unpacking a multi-gigabyte file with
7-Zip first. balenaEtcher can even flash straight from the download address:
[Getting Started](../../getting-started.md) has a **Copy address** button next
to each image.

## A quieter browser { #a-quieter-browser }

The device's browser now has the parts a wall dashboard has no use for turned
off: AI features, translation, spellcheck, sync, metrics and crash reports, and
password and address autofill. They no longer show up in the touch menu or run
in the background. That also stops Chromium from downloading its multi-gigabyte
on-device AI model onto the SD card.

## Fixes { #fixes }

- **Updates finish with a restart** (1.3.1). An update used to switch the
  running system and keep the old dashboard session, so some changes only took
  effect at the next restart. That is why updating from 1.2.0 to 1.3.0 left the
  Button bar switch failing.
- **The update shows up soon after a restart** (1.3.1). On Wi-Fi the first
  release check could fail before the network was up, and the device then waited
  an hour to try again. It now tries again within a minute.
- **The bar fits on the Raspberry Pi Touch Display 2** and keeps its size when
  the display is rotated.
- **A USB touchscreen rotates with the display**, so touches land where you tap.
- **The on-screen keyboard fits a portrait 1024×600 panel.**

## Integration 1.2.0 to 1.2.2 { #integration }

Integration 1.2.0 brings the entities above: **Button bar**, **Screen saver
brightness**, **Reload page**, **Audio output** and **Audio input**, **Charge
start** and **Charge stop**, plus the **Time zone and language** options and
adding a device by its address. It is also the first full release with the
**VNC** switch from [Dashboard Assistant 1.2.0](1.2.0.md).

- **1.2.1**: **Check for updates** in Home Assistant now asks the device to look
  for a new release right away.
- **1.2.2**: Home Assistant picks up the device's new version and entities after
  an OS update. Before, they only appeared once Home Assistant was restarted.

## Updating { #updating }

Update the integration from the Marketplace and restart Home Assistant. Then
install the OS update from Home Assistant, and press **Reboot** once it is
installed. Or flash a fresh image from [Getting Started](../../getting-started.md).
The full lists of changes are in the release notes for
[1.3.0](https://github.com/ajfriesen/DashboardAssistant/releases/tag/v1.3.0),
[1.3.1](https://github.com/ajfriesen/DashboardAssistant/releases/tag/v1.3.1)
and the
[integration](https://github.com/ajfriesen/dashboard-assistant-integration/releases/tag/v1.2.2).
