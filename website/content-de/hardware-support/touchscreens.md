# Touchscreens

Für einen fest montierten Bildschirm ist ein Touchscreen empfehlenswert: Damit
weckst du das Display auf und nutzt die Bedienelemente auf dem Bildschirm.
Zwingend ist er aber nicht.

## Getestete Displays { #tested-displays }

Die offiziellen Touch-Displays von Raspberry Pi sind getestet und funktionieren:

- **[Raspberry Pi Touch Display (7 Zoll)](https://www.raspberrypi.com/documentation/accessories/display.html#raspberry-pi-touch-display)** — getestet und funktioniert.
- **[Raspberry Pi Touch Display 2 (10 Zoll)](https://www.raspberrypi.com/documentation/accessories/touch-display-2.html#raspberry-pi-touch-display-2)** — getestet und funktioniert.
