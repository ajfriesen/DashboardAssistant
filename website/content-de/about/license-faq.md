# Lizenz-FAQ

Diese FAQ ist eine Orientierungshilfe. Im Zweifel gilt der englische
[Lizenztext](license.md).

## Was erlaubt die Lizenz von Dashboard Assistant, kurz zusammengefasst? { #can-you-summarize-what-is-allowed-with-dashboardassistants-license }

Die Lizenz gibt dir kostenlos das Recht, den Quellcode von Dashboard Assistant für jeden nicht-kommerziellen Zweck zu nutzen, zu verändern und weiterzugeben.
Das umfasst private Nutzung und Hobbyprojekte, gemeinnützige Organisationen sowie Schulen, Universitäten, öffentliche Forschungseinrichtungen, Behörden und Organisationen für öffentliche Sicherheit, Gesundheit oder Umweltschutz – unabhängig davon, wie sie finanziert werden.
Die Lizenz soll so freizügig wie möglich sein und Dashboard Assistant zugleich vor Missbrauch schützen.


## Welche Freiheiten habe ich als Nutzer von Dashboard Assistant unter dieser Lizenz? { #what-are-my-freedoms-as-a-dashboardassistant-user-under-this-license }

Wenn du Dashboard Assistant für einen nicht-kommerziellen Zweck nutzt, hast du fast alle Freiheiten einer Open-Source-Lizenz: Du darfst den Quellcode von Dashboard Assistant einsehen, verändern und weitergeben.

## Darf ich Dashboard Assistant forken? { #can-i-fork-dashboardassistant }

Ja. Solange deine Nutzung nicht-kommerziell ist, darfst du Dashboard Assistant unter denselben Lizenzbedingungen forken, verändern und weitergeben.

## Kann ich zu Dashboard Assistant beitragen? { #can-i-contribute-to-dashboardassistant }

Ja.
Bei Bugs oder Feature-Wünschen fragst du am besten in den GitHub Discussions.

Du kannst mir auch eine E-Mail schreiben: andrej@dashboardassistant.org

Code-Beiträge nehme ich im Moment nicht an, schlicht aus Zeitgründen und wegen des ganzen AI-Slops da draußen.
Das Projekt ist jung, und ich will zuerst sicherstellen, dass es in die richtige Richtung geht.



## Darf ich Dashboard Assistant verkaufen? { #can-i-sell-dashboardassistant }

Nein.
Dashboard Assistant zu verkaufen ist unter unserer Lizenz nicht erlaubt. Dazu zählen auch vorgeflashte Hardware mit Dashboard Assistant oder davon abgeleiteten Versionen, Support-Dienstleistungen für Dashboard Assistant oder davon abgeleitete Versionen und Ähnliches.

Wenn dich einer dieser Anwendungsfälle interessiert, melde dich gern bei mir: andrej@dashboardassistant.org.

## Darf ich Videos, Blogposts oder Tutorials über Dashboard Assistant machen? { #can-i-make-videos-blog-posts-or-tutorials-about-dashboardassistant }

Ja, sehr gern – auch auf monetarisierten Kanälen.

Über Dashboard Assistant zu schreiben, es zu testen, zu streamen oder anderen die Bedienung beizubringen ist immer erlaubt, auch wenn dein Kanal oder deine Website mit Werbung, Sponsoring oder Patreon Geld verdient.
Dashboard Assistant zu betreiben, um solche Inhalte zu erstellen, zählt als erlaubter nicht-kommerzieller Zweck, und Screenshots und Bildschirmaufnahmen darfst du frei verwenden.

Du darfst den Namen Dashboard Assistant verwenden, um zu beschreiben, worum es in deinen Inhalten geht.
Bitte verwende Namen oder Logo nicht so, dass der Eindruck entsteht, deine Inhalte seien offiziell oder vom Projekt unterstützt.

Was das nicht abdeckt: Dashboard Assistant selbst zu verkaufen oder Hardware, auf der es vorinstalliert ist – siehe oben „Darf ich Dashboard Assistant verkaufen?“.

## Ist Dashboard Assistant Open Source? { #is-dashboardassistant-open-source }

Nach der Definition der Open Source Initiative (OSI) ist es nicht Open Source.
Es wäre „Source Available“.
